## Test Scenarios

1. **Basic Scanning**
   - Scan finds skills in expected locations
   - Scan handles empty directories gracefully
   - Scan reports no skills found

2. **Mode-Specific**
   - `--all` scans both repo and home
   - `--user` only scans home
   - `--repo` fails outside git repo
   - `--tool` only scans specified tool

3. **Validation**
   - Valid skills reported as valid
   - Invalid skills reported with errors
   - Warnings shown for Claude extensions

4. **Edge Cases**
   - Duplicate skill detection
   - Permissions errors
   - Malformed skill directories
   - Invalid tool names

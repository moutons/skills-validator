## Changes Required

### File: src/cli.rs

Add to the `Commands` enum:

```rust
#[derive(Subcommand)]
#[command(arg_required_else_help = true)]
enum Commands {
    // ... existing commands
    
    /// Scan for and validate skills across multiple directories
    ///
    /// Automatically discovers skills in known agent tool directories
    /// and validates them against the Agent Skills specification.
    Scan(ScanArgs),
}

#[derive(Args)]
#[command(group = ArgGroup::new("scan_mode").required(true))]
struct ScanArgs {
    /// Scan all known paths ($CWD→repo root + $HOME)
    #[arg(long, group = "scan_mode")]
    all: bool,
    
    /// Scan user home directory for all tool paths
    #[arg(long, group = "scan_mode")]
    user: bool,
    
    /// Scan current repository (requires git repo)
    #[arg(long, group = "scan_mode")]
    repo: bool,
    
    /// Scan paths for specific tool(s), comma-separated
    /// 
    /// Available tools: agents, amp, autohand, claude-code, cursor, etc.
    #[arg(long, group = "scan_mode", value_delimiter = ',', value_name = "TOOLS")]
    tool: Vec<String>,
    
    /// Discover skills without validating
    #[arg(long)]
    dry_run: bool,
    
    /// Show detailed output for each skill
    #[arg(short, long)]
    verbose: bool,
}
```

Update the `match cli.command` block to handle the new command.

## Scope

Implementation of the `scan` subcommand and its argument parsing.

## Interface

```rust
#[derive(Subcommand)]
enum Commands {
    Scan(ScanArgs),
    // ... existing commands
}

#[derive(Args)]
struct ScanArgs {
    #[arg(group = "scan_mode")]
    all: bool,
    
    #[arg(group = "scan_mode")]
    user: bool,
    
    #[arg(group = "scan_mode")]
    repo: bool,
    
    #[arg(group = "scan_mode", value_delimiter = ',')]
    tool: Vec<String>,
    
    #[arg(long)]
    dry_run: bool,
    
    #[arg(short, long)]
    verbose: bool,
}
```

## Behavior

### Mode Selection
- Exactly one of `--all`, `--user`, `--repo`, or `--tool` must be provided
- Clap's argument groups enforce mutual exclusivity

### Mode Implementations

#### --all
1. Detect git repository root (if any)
2. Scan $CWD→repo root for tool directories
3. Scan $HOME for tool directories
4. If no git repo found, log INFO and skip repo scan

#### --user
1. Scan $HOME for all tool directories defined in paths.jsonc

#### --repo
1. Detect git repository root
2. If not in a repo, exit with code 2 and error message
3. Scan $CWD→repo root for tool directories

#### --tool <tools>
1. Parse comma-separated tool list
2. Normalize tool names (kebab-case)
3. Validate tool names against paths.jsonc
4. If invalid tool name, show available tools and exit with usage
5. Scan both repo (if any) and $HOME for specified tool directories

## Objective

Add automatic path scanning and validation of all skills found across multiple agent tool directories.

## User Story

As a developer managing skills for multiple agent tools, I want to validate all skills across all known paths so that I can ensure consistency and catch issues early.

## Requirements Summary

### Commands
```bash
skills-validator scan [--all | --user | --repo | --tool <tools>]
```

### Options
- `--all`: Scan $CWD→repo root + $HOME
- `--user`: Scan $HOME for all tool directories
- `--repo`: Scan $CWD→repo root (requires git repo)
- `--tool <tools>`: Scan paths for specific tool(s) (comma-separated)
- `--dry-run`: Discover without validating
- `--verbose`: Show detailed output per skill

### Output
- Default: Structured text summary
- `--json`: JSON output for CI/scripting
- Exit codes: 0=all valid, 1=some invalid, 2=scan/system errors

### Environment Variable Handling
- `$HOME`: Use `dirs` crate
- `$REPO_ROOT`: Use `git2` crate to detect repo root
- `$CWD`: NOT SUPPORTED (Codex-specific behavior, skip it)

## Dependencies

- `git2` crate for repository detection
- `dirs` crate for home directory
- `serde` with JSONC support (or strip comments before parsing)
- `rayon` or `tokio` for parallel validation

## Notes

- paths.jsonc is embedded at compile time via `include_str!`
- Tool names are normalized (kebab-case keys map to display names)
- Unknown tool names show available tools and exit with usage help
- No skills found = warning (not error)

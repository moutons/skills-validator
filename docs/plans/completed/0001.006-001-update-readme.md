Add to "Commands" section after existing commands:

```markdown
```bash
# Scan and validate all skills across known paths
skills-validator scan --all

# Scan only user home directory
skills-validator scan --user

# Scan current repository (requires git repo)
skills-validator scan --repo

# Scan specific tool paths
skills-validator scan --tool claude-code
skills-validator scan --tool claude-code,cursor,opencode

# Dry run - discover without validating
skills-validator scan --all --dry-run

# Verbose output
skills-validator scan --all --verbose

# JSON output for CI
skills-validator scan --all --json
```
```

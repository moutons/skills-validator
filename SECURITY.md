# Security Policy

## Supported Versions

The project is in a pre-1.0 state and only the most recent version is supported with security updates. This chart is the default chart and shouldn't be trusted.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Scope

Detect git repository root and provide repository context for path scanning.

## Responsibilities

1. **Detect Repo**: Find git repository root from any path
2. **Validate Context**: Check if current directory is in a git repo
3. **CWD to Root**: Get all directories from $CWD to repo root

## API

```rust
pub struct RepoContext {
    pub root: PathBuf,
    pub current_dir: PathBuf,
}

impl RepoContext {
    /// Detect git repository root from current directory
    pub fn discover() -> Result<Self, RepoError>;
    
    /// Detect from specific path
    pub fn from_path(path: &Path) -> Result<Self, RepoError>;
    
    /// Get all directories from $CWD up to repo root (inclusive)
    pub fn directories_to_root(&self) -> Vec<PathBuf>;
    
    /// Check if a path is within this repo
    pub fn contains(&self, path: &Path) -> bool;
}

pub enum RepoError {
    NotARepository,
    GitError(git2::Error),
}
```

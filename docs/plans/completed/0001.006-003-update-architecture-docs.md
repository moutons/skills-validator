### Add Parallel Validation Section

Under "Key Algorithms":

```markdown
### Parallel Validation

The scanner uses rayon for parallel validation of discovered skills:

```rust
skills.par_iter_mut().for_each(|skill| {
    skill.validation = validate(&skill.path);
});
```

This provides significant performance improvements when scanning many skills.
```

### Add Configuration Embedding Section

```markdown
### Configuration Embedding

The paths.jsonc file is embedded at compile time using `include_str!`:

```rust
const RAW_CONFIG: &str = include_str!("../paths.jsonc");
```

This ensures the validator always has the latest path configuration without runtime file dependencies.
```

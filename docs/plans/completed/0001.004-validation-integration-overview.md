## Scope

Integrate parallel validation of discovered skills with proper result aggregation.

## Responsibilities

1. **Discovery**: Find all skill directories in given paths
2. **Parallel Validation**: Validate skills concurrently
3. **Result Aggregation**: Collect and summarize results
4. **Duplicate Detection**: Detect same skill in multiple locations
5. **Exit Code Logic**: Determine appropriate exit code

## Data Structures

```rust
pub struct ScanResult {
    pub skills: Vec<ScannedSkill>,
    pub duplicates: Vec<DuplicateSkill>,
    pub errors: Vec<ScanError>,
}

pub struct ScannedSkill {
    pub name: String,
    pub path: PathBuf,
    pub validation: ValidationResult,
}

pub struct DuplicateSkill {
    pub name: String,
    pub paths: Vec<PathBuf>,
}

pub struct ScanError {
    pub path: PathBuf,
    pub error: String,
}
```

## API

```rust
pub async fn scan_and_validate(
    paths: &[PathBuf],
    dry_run: bool,
) -> ScanResult;

pub fn aggregate_results(results: &[ScannedSkill]) -> (usize, usize, usize);  // (valid, invalid, warnings)

pub fn determine_exit_code(result: &ScanResult) -> i32;
```

## Output Formats

### Default (Summary)
```
Found 12 skills in 4 directories
Valid: 10 | Invalid: 1 | Warnings: 1

Invalid skills:
  - my-skill (/home/user/.claude/skills/my-skill)
    Error: Missing required field 'description'

⚠️  1 duplicate skill detected: my-skill exists in multiple locations.
   Your tool may not behave as expected. Check your tool's documentation.
```

## Scope

Parse and provide access to the embedded `paths.jsonc` configuration.

## Data Structure

```rust
pub struct ToolConfig {
    pub name: String,
    pub documentation: Option<String>,
    pub directories: Vec<PathTemplate>,
}

pub struct PathTemplate {
    pub template: String,
    pub requires_repo: bool,  // true if contains $REPO_ROOT
}

pub struct PathsConfig {
    pub tools: HashMap<String, ToolConfig>,  // kebab-case key -> config
}
```

## Responsibilities

1. **Parse JSONC**: Strip comments, parse as JSON at compile time
2. **Normalize Keys**: Convert tool names to kebab-case
3. **Path Expansion**: Replace `$HOME` and `$REPO_ROOT` at runtime
4. **Lookup**: Find tool config by normalized name
5. **List Tools**: Return all available tool names

## API

```rust
impl PathsConfig {
    /// Load config from embedded paths.jsonc
    pub fn load() -> Result<Self, ConfigError>;
    
    /// Get tool config by normalized name
    pub fn get_tool(&self, name: &str) -> Option<&ToolConfig>;
    
    /// List all available tool names
    pub fn tool_names(&self) -> Vec<&str>;
    
    /// Check if tool exists
    pub fn has_tool(&self, name: &str) -> bool;
    
    /// Get all paths for a tool (expanding $HOME and $REPO_ROOT)
    pub fn expand_paths(&self, tool: &str, repo_root: Option<&Path>) -> Vec<PathBuf>;
}
```
